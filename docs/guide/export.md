# 数据导出

GoPaste 支持将完整的剪贴板历史导出为 JSON 文件，让你完全掌控自己的数据。

## 导出步骤

1. 从系统托盘打开**设置**
2. 进入**数据**部分
3. 点击**导出**
4. 选择保存位置

导出文件包含所有剪贴板条目的 JSON 数据，包括时间戳、内容类型和收藏状态。

## JSON 格式

```json
[
  {
    "id": 1,
    "content": "你好，世界！",
    "type": "text",
    "created_at": "2026-01-15T10:30:00Z",
    "is_favorite": false,
    "is_pinned": false
  }
]
```

## 使用场景

- **备份**：升级或重装前保留备份
- **迁移**：将历史记录迁移到新机器
- **分析**：用其他工具处理剪贴板历史数据
