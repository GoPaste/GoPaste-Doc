# 剪贴板历史

GoPaste 自动记录你复制到剪贴板的所有内容——无需任何手动操作。

## 支持的内容类型

| 类型 | 说明 |
|------|------|
| **文本** | 纯文本、多行内容、代码片段 |
| **图片** | 截图、照片、图形 |
| **链接** | URL 被单独识别和分类 |
| **文件** | 从文件管理器复制的文件路径 |

## 工作原理

GoPaste 在后台运行一个监听器，监听操作系统的剪贴板变更事件。当内容发生变化时：

1. 捕获新条目
2. 如果启用了加密（默认开启），使用 AES-256-GCM 加密
3. 存储到本地 SQLite 数据库
4. 显示在历史列表顶部

## 浏览历史

按 <kbd>Alt</kbd> + <kbd>`</kbd> 打开面板查看历史记录。条目按最新在前排序。每个条目显示：

- 内容**预览**（长内容会截断显示）
- **内容类型**图标
- 复制时间的**时间戳**

## 管理条目

- **粘贴条目**：点击条目，或选中后按 <kbd>Enter</kbd>
- **删除条目**：选中后按 <kbd>Delete</kbd>
- **收藏条目**：点击星形图标标记为收藏

## 存储限制

默认情况下，GoPaste 保留一定数量的滚动历史。收藏和置顶的条目永远不会被自动清理。
