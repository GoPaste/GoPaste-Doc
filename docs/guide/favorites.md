# 收藏与置顶

GoPaste 允许你标记重要的剪贴板条目，让它们永远可访问。

## 收藏条目

点击条目上的**星形图标**即可收藏。收藏的条目：

- **永不被自动删除**（不受滚动历史清理影响）
- 可通过收藏视图快速访问

## 置顶条目

置顶的条目始终显示在**列表顶部**，无论它们是何时复制的。适用于频繁访问的片段——如邮件地址、常用代码模板或常用短语。

在条目的上下文菜单中选择置顶操作。

## 使用场景

- **代码片段**：置顶常用的样板代码或模板
- **服务器地址**：保留常用服务器或 API 端点地址
- **文档模板**：置顶邮件签名、文档标题或常用回复模板
- **参考文本**：置顶任务期间需要反复查阅的文本
