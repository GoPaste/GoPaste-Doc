# 快捷键

GoPaste 以键盘操作为核心设计，尽量减少鼠标使用。

## 全局快捷键

全局快捷键可以从**任意应用**打开 GoPaste 面板，即使 GoPaste 不在前台也有效。

**默认：** <kbd>Alt</kbd> + <kbd>`</kbd>

再次按下相同快捷键（或按 <kbd>Esc</kbd>）关闭面板。

## 自定义全局快捷键

在**设置**中修改全局快捷键：

1. 点击系统托盘中的 GoPaste 图标
2. 打开**设置**
3. 找到快捷键设置区域
4. 点击快捷键输入框，按下你想要的组合键
5. 保存

::: tip 建议
选择不与其他应用冲突的组合键，常用选择包括：
- <kbd>Alt</kbd> + <kbd>V</kbd>
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd>
- <kbd>Alt</kbd> + <kbd>Space</kbd>
:::

## 面板内导航快捷键

这些快捷键在面板打开时有效：

| 键 | 动作 |
|----|------|
| `↑` / `↓` | 在条目间导航 |
| `Tab` | 切换到下一个内容类型筛选 |
| `Shift+Tab` | 切换到上一个内容类型筛选 |
| `Enter` | 粘贴选中条目 |
| `Delete` | 删除选中条目 |
| `Esc` | 关闭面板 |
