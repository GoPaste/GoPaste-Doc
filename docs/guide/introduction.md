# 简介

**GoPaste** 是一款轻量、快速、安全的跨平台剪贴板管理工具。它在后台静默监听剪贴板活动，并通过全局快捷键让你随时访问完整的剪贴板历史——无需切换窗口。

## 为什么选择 GoPaste？

现代工作流中充满了复制粘贴操作。无论你是开发者、写作者还是设计师，一定都有过因意外覆盖剪贴板而丢失重要内容的经历。GoPaste 优雅地解决了这个问题：

- **零摩擦** — 后台运行，无需手动操作即可自动记录
- **即时检索** — 全局快捷键在 100ms 内呼出历史记录
- **隐私优先** — 所有数据保留在本地设备，静态加密存储

## 功能一览

| 功能 | 描述 |
|------|------|
| 自动记录 | 监听剪贴板的文本、图片、链接、代码和文件 |
| 即时访问 | 全局快捷键 <code>Alt + `</code> 打开面板 |
| 智能搜索 | 实时全文搜索 + 类型筛选 |
| 收藏功能 | 标记条目永久保留，置顶到列表顶部 |
| AES-256 加密 | 所有存储内容加密，密钥保存在系统 Keychain |
| 跨平台 | Windows、macOS、Linux 一套代码 |
| 双主题 | 深色和浅色模式 |
| 多语言 | 简体中文、繁體中文、English |
| 数据导出 | 一键 JSON 导出 |

## 技术栈

GoPaste 基于以下技术构建：

- **后端**：Go + [Wails v2](https://wails.io/)（基于 WebView 的桌面应用框架）
- **前端**：Vue 3 + TypeScript + Vite
- **存储**：SQLite（纯 Go 实现，无 CGO 依赖）
- **加密**：AES-256-GCM + 系统 Keychain
