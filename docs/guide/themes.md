# 主题切换

GoPaste 支持深色和浅色两种主题，适应不同的系统偏好和个人习惯。

## 切换主题

从系统托盘图标打开**设置**，在主题选项中切换：

- **深色模式** — 低光环境下更护眼
- **浅色模式** — 明亮环境下清晰简洁

切换主题无需重启应用，即时生效。
