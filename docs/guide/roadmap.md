# 路线图

GoPaste 正在积极开发中，以下是规划中的功能：

## 计划中

- [ ] **导入数据** — 从 JSON 备份文件恢复剪贴板历史
- [ ] **富文本 / HTML** — 从网页和文档复制时保留格式
- [ ] **自动更新** — 应用内下载并安装新版本
- [ ] **Linux 分发包** — AppImage、`.deb`、`.rpm` 格式
- [ ] **数字键快速粘贴** — 按 `1–9` 直接粘贴对应条目
- [ ] **多设备 E2E 加密同步** — 端对端加密跨设备同步剪贴板历史

## 已完成

- [x] **CI/CD 自动构建** — GitHub Actions 自动化多平台构建和发布
- [x] **AES-256 加密** — 本地加密存储，密钥保存在系统 Keychain
- [x] **多语言支持** — 简体中文、繁體中文、English
- [x] **跨平台** — Windows、macOS、Linux 单一代码库
- [x] **收藏与置顶** — 标记重要条目，置顶到列表顶部
- [x] **数据导出** — 一键 JSON 导出
