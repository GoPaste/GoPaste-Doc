# 快速上手

一分钟内开始使用 GoPaste。

## 第一步：启动 GoPaste

安装完成后，启动 GoPaste。应用将会：
- 静默在后台运行
- 在系统托盘中显示图标
- 自动开始监听剪贴板

## 第二步：正常复制内容

像平时一样复制任意内容——文本、图片、链接、代码片段。GoPaste 自动记录一切，无需额外操作。

## 第三步：呼出面板

按下 <kbd>Alt</kbd> + <kbd>`</kbd>，从任意应用中即时呼出 GoPaste 面板。

![GoPaste 面板](/images/main_zh_sc.png)

## 第四步：粘贴历史内容

- **浏览**：滚动查看剪贴板历史
- **搜索**：开始输入，实时筛选条目
- **选择**：用 <kbd>↑</kbd> / <kbd>↓</kbd> 方向键导航
- **粘贴**：按 <kbd>Enter</kbd> 将选中条目粘贴到当前应用

粘贴完成后，面板自动关闭。

## 快捷键速查

| 键 | 动作 |
|----|------|
| <code>Alt + `</code> | 打开 / 关闭面板 |
| `Tab` / `Shift+Tab` | 切换内容类型筛选 |
| `↑` / `↓` | 上下选择条目 |
| `Enter` | 粘贴选中条目 |
| `Esc` | 关闭面板 |
| `Delete` | 删除选中条目 |
