# 搜索与筛选

GoPaste 提供实时全文搜索，帮你在毫秒内找到任意剪贴板条目。

## 使用搜索

打开面板后，直接开始输入即可搜索。列表随输入实时更新——无需按 Enter。

搜索会匹配每个剪贴板条目的完整内容。

## 类型筛选

使用 <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> 切换内容类型筛选：

| 筛选 | 显示内容 |
|------|----------|
| 全部 | 所有剪贴板条目 |
| 文本 | 纯文本条目 |
| 图片 | 图片和截图 |
| 链接 | URL 和网址 |
| 文件 | 文件路径 |

类型筛选可与文本搜索组合使用——例如，筛选「链接」类型后输入关键词，快速找到特定 URL。

## 使用技巧

- 搜索不区分大小写
- 支持部分匹配——搜索"git"会匹配"git commit"、"github.com"等
- 收藏条目与普通条目一同出现在搜索结果中
