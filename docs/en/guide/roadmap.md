# Roadmap

GoPaste is actively developed. Here's what's planned:

## In Progress / Planned

- [ ] **Data import** — Restore clipboard history from a JSON backup file
- [ ] **Rich text / HTML** — Preserve formatting when copying from web pages and documents
- [ ] **Auto-update** — In-app download and install of new versions
- [ ] **Linux packages** — AppImage, `.deb`, and `.rpm` distribution formats
- [ ] **Quick-paste with number keys** — Press `1–9` to directly paste the corresponding item
- [ ] **Multi-device E2E encrypted sync** — Sync clipboard history across devices with end-to-end encryption

## Completed

- [x] **CI/CD automated builds** — Automated multi-platform builds and releases via GitHub Actions
- [x] **AES-256 encryption** — Local encryption with system Keychain key storage
- [x] **Multilingual support** — Simplified Chinese, Traditional Chinese, English
- [x] **Cross-platform** — Windows, macOS, Linux from a single codebase
- [x] **Favorites & pin** — Mark important items, pin to top of list
- [x] **Data export** — One-click JSON export
