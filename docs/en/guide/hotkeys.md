# Hotkeys

GoPaste is designed to be keyboard-driven, minimizing the need to reach for the mouse.

## Global Hotkey

The global hotkey opens the GoPaste panel from **any application**, even when GoPaste is not in focus.

**Default:** <kbd>Alt</kbd> + <kbd>`</kbd>

Press the same hotkey again (or press <kbd>Esc</kbd>) to close the panel.

## Customizing the Global Hotkey

You can change the global hotkey in **Settings**:

1. Click the GoPaste icon in your system tray
2. Open **Settings**
3. Navigate to the hotkey section
4. Click the hotkey field and press your desired key combination
5. Save

::: tip
Choose a combination that doesn't conflict with your other applications. Common choices include:
- <kbd>Alt</kbd> + <kbd>V</kbd>
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd>
- <kbd>Alt</kbd> + <kbd>Space</kbd>
:::

## Panel Navigation Shortcuts

These shortcuts work when the panel is open:

| Key | Action |
|-----|--------|
| `↑` / `↓` | Navigate between items |
| `Tab` | Next content type filter |
| `Shift+Tab` | Previous content type filter |
| `Enter` | Paste selected item |
| `Delete` | Delete selected item |
| `Esc` | Close panel |
