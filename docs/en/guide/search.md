# Search & Filter

GoPaste provides real-time full-text search to help you find any clipboard item in milliseconds.

## Using Search

When the panel is open, simply start typing to search. The list updates instantly as you type — no need to press Enter.

Search matches against the full content of each clipboard item.

## Type Filtering

Use <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> to cycle through content type filters:

| Filter | Shows |
|--------|-------|
| All | All clipboard items |
| Text | Plain text items |
| Image | Images and screenshots |
| Link | URLs and web addresses |
| File | File paths |

You can combine type filtering with text search — for example, filter to "Link" and type a keyword to find a specific URL.

## Tips

- Search is case-insensitive
- Partial matches work — searching "git" will match "git commit", "github.com", etc.
- Favorited items appear mixed with regular items in search results
