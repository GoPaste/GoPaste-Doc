# Favorites & Pin

GoPaste lets you mark important clipboard items to keep them accessible forever.

## Favoriting Items

To favorite an item, click the **star icon** on any clipboard item in the panel. Favorited items:

- Are **never automatically deleted** by the rolling history cleanup
- Can be accessed quickly by filtering to the Favorites view

## Pinning Items

Pinned items always appear at the **top of the list**, regardless of when they were copied. This is useful for snippets you access frequently — like your email address, common code templates, or frequently used phrases.

To pin an item, use the pin action in the item's context menu.

## Use Cases

- **Code snippets**: Pin frequently used boilerplate or templates
- **Credentials**: Keep a masked reference to server addresses (note: actual sensitive passwords should use a dedicated password manager)
- **Templates**: Keep email signatures, document headers, or reply templates pinned
- **Reference text**: Pin text you need to consult repeatedly during a task
