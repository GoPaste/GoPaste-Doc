# Quick Start

Get up and running with GoPaste in under a minute.

## Step 1: Launch GoPaste

After installation, launch GoPaste. The application will:
- Start silently in the background
- Appear as an icon in your system tray
- Begin monitoring your clipboard automatically

## Step 2: Copy Something

Just copy any content as you normally would — text, images, links, code snippets. GoPaste records everything automatically. No extra steps needed.

## Step 3: Open the Panel

Press <kbd>Alt</kbd> + <kbd>`</kbd> to open the GoPaste panel instantly, from any application.

![GoPaste Panel](/images/main_en.png)

## Step 4: Paste Your History

- **Browse**: Scroll through your clipboard history
- **Search**: Start typing to filter items in real-time
- **Select**: Use <kbd>↑</kbd> / <kbd>↓</kbd> arrows to navigate
- **Paste**: Press <kbd>Enter</kbd> to paste the selected item into your current app

The panel will close automatically after pasting.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <code>Alt + `</code> | Open/close the panel |
| `Tab` / `Shift+Tab` | Switch content type filter |
| `↑` / `↓` | Navigate items |
| `Enter` | Paste selected item |
| `Esc` | Close the panel |
| `Delete` | Delete selected item |
