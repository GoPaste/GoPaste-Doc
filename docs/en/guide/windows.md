# Windows Notes

GoPaste has native Windows integration and is one of the simplest platforms to get started on.

## Installation Options

### Portable Version (Recommended for Quick Start)
- Download `GoPaste_x.x.x_windows_x64-portable.exe`
- Double-click to run — no installation required
- Place it anywhere: Desktop, USB drive, a folder you prefer

### Installer Version
- Download `GoPaste_x.x.x_windows_x64-setup.exe`
- Run the installer wizard
- GoPaste installs to Program Files and creates Start Menu shortcuts
- Can be uninstalled via Windows Settings → Apps

## Auto-Start on Login

To have GoPaste start automatically when you log in to Windows, enable **Launch at Login** in GoPaste Settings.

## System Tray

GoPaste lives in the Windows system tray (notification area, bottom-right corner). If you don't see it, click the **^** arrow to expand hidden icons.

Right-click the tray icon to access:
- Open panel
- Settings
- Quit

## SmartScreen Warning

On first launch, Windows SmartScreen may show a warning: "Windows protected your PC." This is because GoPaste is not yet signed with a commercial code-signing certificate.

To proceed: click **More info** → **Run anyway**.

## Architecture

- **x64**: For 64-bit Windows (almost all modern PCs)
- **x86**: For older 32-bit Windows systems

If you're unsure, use the x64 version.
